***MLOGE Shop*** - это вёрстка сайта магазина одежды с несколькими страницами. 
Страница с товарами и выбор категории товаров. Страница с конкретным товаром и информацией. 
Регистрация/аутентификация, страница профиля. Добавление товаров в избранные и корзина товаров.

## Что сделано и как?

***MLOGE Shop*** - это только фронтенд часть приложения, которая без запущенного [бэкенда](https://github.com/Androoomeda/ShopApi) работать не будет.
***ShopWebsite*** посылает api запросы к бэкенду и получает обратную информацию которую отрисовывает на странице.

Пример api запросов
```javascript
export const getProducts = () => apiRequest('/api/products');

export const getProductById = productId =>
  apiRequest(`/api/products/${productId}`, { credentials: 'include' });
```

Авторизация пользователя происходит с помощью ***JWT*** токена, хранимого в куки файлах и генерируемого на бэкенде. 

> [!NOTE]
> Неавторизованный пользователь ограничен в функционале сайта и поэтому может только смотреть товары, 
для покупки и добавления в избранного ему нужно зарегистрироваться.

## Как это выглядит?

### Главная страница - mainPage.html
- Карточками товаров, ценами, описанием и кнопкой лайка;
- логотипом магазина, городом;
- кнопками навигации для перехода в профиль, избранные товары, корзину;
- счётчик количества товаров в избранном и корзине;
- остальными навигационными ссылками внизу страницы
